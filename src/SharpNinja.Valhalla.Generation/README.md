# SharpNinja.Valhalla.Generation

`SharpNinja.Valhalla.Generation` contains the build-time APIs for producing, validating, and qualifying Valhalla graph generations from .NET.

The package is under BDPv4 qualification against Valhalla 3.8.3. It is not the canonical production generator until the semantic-parity, Nashville performance, Lower-48 cadence, stability, canary, and rollback gates pass.

The Android- and embedded-routing runtime remains in the separate `SharpNinja.Valhalla` package.
